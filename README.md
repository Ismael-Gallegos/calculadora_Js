\# Calculadora básica en JavaScript



Este repositorio contiene el desarrollo del \*\*Reto 4\*\* del módulo \*Programación Web del Lado del Cliente\* de UVEG.



La calculadora incluye:



\- Botones del 0 al 9  

\- Operaciones básicas: suma, resta, multiplicación y división  

\- Botón de resultado (=)  

\- Botón de limpiar (C)  

\- Pantalla para mostrar operaciones y resultados  



El proyecto está construido con \*\*HTML, CSS y JavaScript\*\*, y forma parte del aprendizaje sobre interacción con el DOM y manejo de eventos.
